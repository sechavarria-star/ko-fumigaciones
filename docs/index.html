Informe consolidado de facturas

Subí el informe general de ventas que exporta el sistema de facturación (un PDF con los comprobantes del período - un mes por vez). Se suma a las facturas que ya tenés cargadas: si un comprobante ya existía se actualiza, si es nuevo se agrega, y los pagos ya conciliados no se tocan. El informe no trae CUIT, así que los clientes que no se puedan asociar automáticamente quedan pendientes de validar.

Facturas pendientes de validar

Estas facturas vinieron del informe consolidado sin poder asociarse solas a un cliente. Confirmá el CUIT correcto para cada nombre - se aplica a todas las facturas de ese nombre de una.
